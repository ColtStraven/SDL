## 2. Decoder changes needed for this replay

- **Format registration.** Magic `0x00018C2D` was not in the version registry. It is now registered as `18c2d` (zstd, 1234-byte header). This file passes the same structural checks as `18c1c`:
  - the zstd magic sits exactly at `1234 + settings_blk_size` (1,981);
  - the frame ends exactly at `footer_blk_offset` (4,954,262), with 0 trailing bytes.
- **Leading record with several weapons.** The ownship parser previously assumed the Me 262's single weapon entry, so it refused all 3,076 F-84B records. It now:
  - reads bits 72–79 as 4 flag bits plus a 4-bit **weapon entry count** (Me 262: 1; F-84B: 14);
  - locates the position as the leading triple equal to the record's trailing position copy (3,065 records). The other 11 reuse the offset from the previous record with the same layout;
  - keeps the Me 262 results unchanged: 2,494/2,494 and 3,141/3,141 altimeter agreement, 0 track jumps, the same counters.
- **Altimeter unit.** The F-84B's cockpit altimeter (id 40) reads **feet**. Read as metres, the median mismatch is 2,580 m; read as feet, 1.0 m. The decoder now chooses metres or feet by which one fits (DERIVED) and reports both medians. Cockpit id 40 is now labelled `altitude` instead of `altitude_m`.
- **Output.** The flight summary schema is now `static57.sdl.flight-summary/0.3`:
  - **New summary fields:** `entry_counts`, `position_sources`, `weapon_block_changes`, `cross_check.altimeter_unit` and the per-unit medians.
  - **New per-sample fields:** `position_source`, `entry_count` and `weapon_block_hex`.
  - **New event:** `weapon_block_change` in `weapons.jsonl`.

## 6. Weapons

The F-84B's weapon block has **14 entries**: 6 of 24 bits, then 8 of 16 bits (EXPERIMENTAL reading).

- **Gun entries:** all six read `6c 02 00` throughout and never change. No firing-flag packets occur, so the replay shows **no gun firing**. It is not established whether these entries are ammunition counts.
- **Store entries:** each starts at `01 00`. They clear one at a time, and the block **refills to 8 twice while airborne**, far from the airfield.
